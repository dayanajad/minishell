Nice, planning for the bonus *from the start* is the right move.
Let’s design a **clean, full set of data structures** for minishell + bonus (AST, redirs, env, etc.) that you can actually implement.

I’ll write this like a `minishell.h` skeleton and explain as we go.

---

## 0. Big Picture: Layers and What Needs Structs

Your shell roughly has:

1. **Lexer** → turns input string into tokens
2. **Parser** → turns tokens into an **AST** (handles `|`, `&&`, `||`, `()`)
3. **Executor** → walks the AST and uses `fork/execve/pipe/dup2`
4. **Env / state** → environment variables, last exit code, etc.

So we’ll design structs for:

* Tokens
* AST nodes (commands, pipes, &&, ||, subshell `( )`)
* Redirections
* Environment
* Shell state

---

## 1. Tokens

You’ll tokenize the input first. That’s much easier than parsing directly from the string.

```c
/* token.h */

#ifndef TOKEN_H
# define TOKEN_H

typedef enum e_token_type
{
    TOK_WORD,       // command or argument or filename (after lexing, before expansion)
    TOK_PIPE,       // |
    TOK_AND_IF,     // &&
    TOK_OR_IF,      // ||
    TOK_REDIR_IN,   // <
    TOK_REDIR_OUT,  // >
    TOK_REDIR_APP,  // >>
    TOK_HEREDOC,    // <<
    TOK_LPAREN,     // (
    TOK_RPAREN,     // )
    TOK_END         // end of input (synthetic)
}   t_token_type;

typedef struct s_token
{
    t_token_type    type;
    char            *value;     // for WORD: string; for others: can be NULL or the symbol
    struct s_token  *next;
}   t_token;

#endif
```

You can store tokens in a **linked list** (simple to build and walk).

---

## 2. Redirections

Commands need to store redirections like `<`, `>`, `>>`, `<<`.

```c
/* ast.h – redirections part */

typedef enum e_redir_type
{
    R_IN,       // <
    R_OUT,      // >
    R_APPEND,   // >>
    R_HEREDOC   // <<
}   t_redir_type;

typedef struct s_redir
{
    t_redir_type    type;
    char            *target;    // filename OR heredoc delimiter
    struct s_redir  *next;
}   t_redir;
```

* For `<` / `>` / `>>` → `target` = filename
* For `<<` → `target` = limiter string

Executor will walk this list and do `open`, `dup2`, etc.

---

## 3. Command Node (leaf of the AST)

A **simple command** (no `|`, no `&&`, no `||`, no `()`):

```bash
ls -l src
echo "hello"
cat file | grep hi   # each side of | is a simple command + redirs
```

Struct:

```c
/* ast.h – command node */

typedef struct s_cmd
{
    char    **argv;     // NULL-terminated array: ["ls", "-l", "src", NULL]
    t_redir *redirs;    // linked list of redirections (can be NULL)
}   t_cmd;
```

You will build `argv` (after expansion and wildcard) as a dynamic array of `char *`.

---

## 4. AST Node Types

For bonus you need AST nodes for:

* simple command
* pipe `|`
* `&&`
* `||`
* subshell `( ... )`

So:

```c
/* ast.h – node types */

typedef enum e_node_type
{
    NODE_CMD,      // simple command (t_cmd)
    NODE_PIPE,     // left | right
    NODE_AND,      // left && right
    NODE_OR,       // left || right
    NODE_SUBSHELL  // ( child )
}   t_node_type;
```

---

## 5. The AST Node Struct

We combine everything into one `t_ast`:

```c
/* ast.h – full AST node */

typedef struct s_ast t_ast;

typedef struct s_binary
{
    t_ast   *left;
    t_ast   *right;
}   t_binary;

struct s_ast
{
    t_node_type type;
    union
    {
        t_cmd    cmd;       // for NODE_CMD
        t_binary bin;       // for PIPE / AND / OR
        t_ast    *child;    // for SUBSHELL: ( child )
    } as;
};
```

How you use it:

* `NODE_CMD`:

  * `node->as.cmd.argv`
  * `node->as.cmd.redirs`
* `NODE_PIPE`:

  * `node->as.bin.left`
  * `node->as.bin.right`
* `NODE_AND` / `NODE_OR`:

  * same as pipe: `as.bin.left/right`
* `NODE_SUBSHELL`:

  * `node->as.child` points to the AST inside `( )`

If you don’t like `union`, you can skip it and just put everything, but union keeps memory tighter.

## 6. Environment Representation

You’ll need to store and manipulate environment (`export`, `unset`, etc).

Simple linked list:

```c
/* env.h */

#ifndef ENV_H
# define ENV_H

typedef struct s_env
{
    char            *key;       // e.g. "PATH"
    char            *value;     // e.g. "/bin:/usr/bin"
    struct s_env    *next;
}   t_env;

#endif
```

At startup, you can build this from `char **envp`.

You may also want a helper to turn it back into `char **` for `execve`.

---

## 7. Shell State (Context)

You want one struct that carries around:

* env list
* last exit status `$?`
* maybe a flag if you’re running or exiting

```c
/* shell.h */

#ifndef SHELL_H
# define SHELL_H

# include "env.h"
# include "ast.h"
# include "token.h"

typedef struct s_shell
{
    t_env   *env;               // environment variables
    int     last_status;        // for $?
    int     should_exit;        // set when builtin exit is called
}   t_shell;

#endif
```

And per subject you’re allowed **one global** for signals only:

```c
/* global.c / global.h */

#include <signal.h>

volatile sig_atomic_t g_signal = 0;   // 0 = none, SIGINT, etc.
```

You **must not** store your whole shell in a global; pass `t_shell *` around.

## 8. How It All Connects (Workflow)

To see why these structs make sense, here’s your future flow:

1. **Readline**

   ```c
   line = readline("minishell$ ");
   ```

2. **Lexing**: string → `t_token` list

3. **Parsing**: tokens → `t_ast *root`

   * handles precedence:

     * parse `NODE_PIPE` first
     * then build `NODE_AND` / `NODE_OR`
     * treat `( ... )` as `NODE_SUBSHELL`

4. **Execution**:

   ```c
   int exec_ast(t_shell *sh, t_ast *node);
   ```

   * `NODE_CMD` → redirs + forks + execve or builtin
   * `NODE_PIPE` → pipe + two forks
   * `NODE_AND` → exec left; if success, exec right
   * `NODE_OR` → exec left; if failure, exec right
   * `NODE_SUBSHELL` → fork, execute `child` in new process

5. Free AST, tokens, temporary stuff (not `readline` internals, that’s allowed to leak).

## 9. Minimal `ast.h` You Can Actually Start From

Here’s a single header you can copy and adapt:

```c
#ifndef AST_H
# define AST_H

typedef enum e_redir_type
{
    R_IN,
    R_OUT,
    R_APPEND,
    R_HEREDOC
}   t_redir_type;

typedef struct s_redir
{
    t_redir_type        type;
    char                *target;
    struct s_redir      *next;
}   t_redir;

typedef struct s_cmd
{
    char    **argv;     // NULL-terminated
    t_redir *redirs;    // linked list
}   t_cmd;

typedef enum e_node_type
{
    NODE_CMD,
    NODE_PIPE,
    NODE_AND,
    NODE_OR,
    NODE_SUBSHELL
}   t_node_type;

typedef struct s_ast  t_ast;

typedef struct s_binary
{
    t_ast   *left;
    t_ast   *right;
}   t_binary;

struct s_ast
{
    t_node_type type;
    union
    {
        t_cmd    cmd;
        t_binary bin;
        t_ast    *child;    // for subshell
    } as;
};

#endif
```
