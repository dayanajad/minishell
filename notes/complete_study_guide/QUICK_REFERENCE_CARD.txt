SYSTEM CALLS CHEAT SHEET
═══════════════════════════════════════════════════════════════════

PROCESS MANAGEMENT:
───────────────────────────────────────────────────────────────────
fork()              Create child process
                    Returns: 0 in child, PID in parent, -1 on error

execve(path, argv, envp)   Replace process with new program
                           Only returns on error!

wait(&status)       Wait for any child
waitpid(pid, &status, 0)   Wait for specific child

exit(status)        Terminate process (0-255)

WIFEXITED(status)   Check if child exited normally
WEXITSTATUS(status) Get exit code (0-255)

FILE DESCRIPTORS:
───────────────────────────────────────────────────────────────────
open(path, flags, mode)    Open file, returns FD
                          Flags: O_RDONLY, O_WRONLY, O_CREAT,
                                 O_TRUNC, O_APPEND

close(fd)           Close file descriptor

dup2(oldfd, newfd)  Duplicate FD to specific number
                    Example: dup2(fd, STDOUT_FILENO)

PIPES:
───────────────────────────────────────────────────────────────────
pipe(pipefd)        Create pipe
                    pipefd[0] = read end
                    pipefd[1] = write end

CRITICAL: Close unused ends in each process!

SIGNALS:
───────────────────────────────────────────────────────────────────
signal(sig, handler)        Simple signal handling
sigaction(sig, &act, NULL)  Advanced signal handling (better!)

SIGINT  = Ctrl-C
SIGQUIT = Ctrl-\
SIG_IGN = Ignore signal
SIG_DFL = Default behavior

DIRECTORY:
───────────────────────────────────────────────────────────────────
getcwd(buf, size)   Get current directory
chdir(path)         Change directory

READLINE:
───────────────────────────────────────────────────────────────────
readline(prompt)    Read line with editing
                    Returns malloc'd string or NULL (Ctrl-D)

add_history(line)   Add to history

═══════════════════════════════════════════════════════════════════
COMMON PATTERNS
═══════════════════════════════════════════════════════════════════

EXECUTE EXTERNAL COMMAND:
───────────────────────────────────────────────────────────────────
pid = fork();
if (pid == 0) {
    // Child
    execve(path, args, envp);
    exit(1);  // Only if execve fails
} else {
    // Parent
    waitpid(pid, &status, 0);
}

REDIRECT OUTPUT TO FILE:
───────────────────────────────────────────────────────────────────
fd = open("file.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
dup2(fd, STDOUT_FILENO);
close(fd);

PIPE BETWEEN TWO COMMANDS:
───────────────────────────────────────────────────────────────────
pipe(pipefd);

// Command 1
if (fork() == 0) {
    close(pipefd[0]);               // Close read
    dup2(pipefd[1], STDOUT_FILENO); // Write to pipe
    close(pipefd[1]);
    execve(...);
}

// Command 2
if (fork() == 0) {
    close(pipefd[1]);               // Close write
    dup2(pipefd[0], STDIN_FILENO);  // Read from pipe
    close(pipefd[0]);
    execve(...);
}

// Parent
close(pipefd[0]);
close(pipefd[1]);
wait(NULL);
wait(NULL);

DATA FLOW
═══════════════════════════════════════════════════════════════════

Input → LEXER → Tokens → PARSER → Commands → EXECUTOR → Output

Example: echo hello | grep h

LEXER:
[WORD:"echo"] → [WORD:"hello"] → [PIPE:"|"] → [WORD:"grep"] → [WORD:"h"]

PARSER:
cmd1: args=["echo", "hello", NULL]
cmd2: args=["grep", "h", NULL]
cmd1->next = cmd2

EXECUTOR:
fork() → echo hello → pipe → grep h → output

═══════════════════════════════════════════════════════════════════
COMMON MISTAKES
═══════════════════════════════════════════════════════════════════

❌ Not closing pipe FDs → Deadlock
❌ Not freeing malloc'd memory → Memory leak
❌ Not checking fork() return → Undefined behavior
❌ Using printf() in signal handler → Undefined behavior
❌ Not waiting for children → Zombie processes
❌ Wrong dup2() parameters → Redirections fail
❌ Expanding $VAR in single quotes → Wrong behavior
❌ Not handling $? → Test failures

DEBUGGING
